Base de Conhecimento SecOps (KB)

Manuais e diretrizes para arquiteturas e controles de conformidade

[KB-1001] Mitigação de OWASP Top 10 A01: Broken Access Control

O controle de acesso em nível de registro deve ser validado via backend. No rebuild em Ruby Sinatra, as operações CRUD realizam verificações rígidas associadas a perfis e identificadores únicos.

Frameworks relacionados: NIST Protect (PR.AC) | ISO 27001 A.9 | SABSA Camada Lógica

[KB-1002] Implementação e Configuração de Cabeçalhos de Segurança HTTP

Para mitigar ataques de clickjacking e Cross-Site Scripting (XSS), foram inseridos filtros de interceptação no backend Sinatra para emitir cabeçalhos HTTP estritos como Content-Security-Policy, X-Frame-Options: DENY e X-Content-Type-Options: nosniff.

Frameworks relacionados: NIST Respond (RS.MI) | CIS Control 4 | ISO 27001 A.12.6
