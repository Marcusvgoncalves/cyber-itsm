OWASP Top 10 for Large Language Models (LLM)

Procedimentos de segurança e remediação para aplicações baseadas em inteligência artificial generativa. Um guia passo a passo do nível Júnior ao Especialista.

LLM01 — Injeção de Prompt (Prompt Injection)

Manipulação de modelos de linguagem de inteligência artificial através de instruções maliciosas inseridas por usuários para contornar restrições de comportamento.

Júnior

  • Procedimento: Trate qualquer saída gerada pelo LLM como código inseguro. Nunca use a resposta diretamente em chamadas de sistema ou renderização HTML sem sanitizar tags.

Pleno

  • Procedimento: Desenvolva validadores estruturados de entrada (limitação de caracteres, remoção de chaves ou caracteres que sinalizem tokens de sistema) e crie scripts de teste automatizados simulando tentativas comuns de quebra de jailbreak (ex: "ignorar instruções anteriores").

Especialista

  • Procedimento: Implemente um firewall semântico ativo de análise de prompt que avalie o vetor de embeddings da entrada do usuário para identificar intenções maliciosas antes do payload atingir o prompt de sistema do modelo (System Prompt isolation).

LLM06 — Vazamento de Informações Sensíveis (Sensitive Information Disclosure)

O LLM expõe acidentalmente dados proprietários corporativos ou informações pessoalmente identificáveis (PII) nas respostas fornecidas.

Júnior

  • Procedimento: Nunca insira dados reais de clientes ou chaves de API nos prompts enviados para modelos públicos (como ChatGPT ou Claude gratuitos). Use sempre dados fictícios em testes locais.

Pleno

  • Procedimento: Desenvolva uma camada de sanitização e mascaramento automático de PII (utilizando Regex ou Name Entity Recognition - NER) antes que os dados sejam enviados à API da IA corporativa.

Especialista

  • Procedimento: Configure modelos locais/privados em nuvem própria e garanta o isolamento do banco de dados vetorial de recuperação (RAG), garantindo que usuários possuam as permissões corretas (RBAC) para ler documentos indexados.
